# 확장 장바구니

확장을 골라 담은 뒤 한 번에 업데이트·켜기·끄기·삭제하고, 새로고침은 마지막에 한 번만 해요.

## 여는 곳
- 입력창 왼쪽 햄버거(≡) 메뉴 맨 아래 → **확장 장바구니**
- 슬래시 명령 `/extcart`

## 쓰는 법
1. 확장 오른쪽 단추로 할 일을 담아요. (↑ 업데이트 · 전원 켜기/끄기 · 휴지통 삭제 · ⋯ 자세히/다시 설치) 같은 단추를 다시 누르면 빠져요.
2. 아래 **적용**을 눌러요. 삭제·끄기·다시 설치가 있으면 확인창이 한 번 떠요.
3. 결과 창에서 **새로고침**을 눌러요.

- **업데이트 있는 것 담기**: 업데이트가 있다고 확인된 확장을 모두 담아요.
- **설정**: 장바구니 위쪽 톱니바퀴 단추에 있어요.
- **다시 확인**: 업데이트 확인을 지금 다시 해요. 결과는 이 기기에 기억돼요(기본 6시간).
- **묶음**: 지금 켜짐·꺼짐 상태를 이름 붙여 저장하고, 불러오면 달라지는 것만 장바구니에 담겨요.
- **다시 설치**: 업데이트가 계속 실패하는 확장을 지우고 같은 주소에서 새로 받아요. 폴더 안에 따로 저장된 파일은 사라져요.

## 알아 둘 점
- 실패한 자세한 이유는 실리태번 서버 창(검은 창)에 나와요. 서버가 화면으로는 이유를 보내 주지 않아요.
- 꺼져 있는 확장의 업데이트·삭제 훅은 부르지 않아요.
- 이 확장은 실리태번 서버의 `/api/extensions/*` 만 호출해요. 다른 곳에 접속하지 않고 API 키·채팅을 읽지 않아요.
